# Overbee Social Hive

OVERBEE — OFFICIAL SOCIAL LINKS

INSTAGRAM
https://www.instagram.com/overbee.ow/

DISCORD
https://discord.gg/zYV9KNcr4

Configure o projeto para utilizar esses links em todo o site.

O link do Discord deverá ser usado nos seguintes botões:

JOIN DISCORD

JOIN THE HIVE

JOIN OUR COMMUNITY

APPLY FOR PC TRYOUT

APPLY FOR CONSOLE TRYOUT

O Instagram deverá ser utilizado nos botões:

FOLLOW US ON INSTAGRAM

OUR INSTAGRAM

INSTAGRAM

Todos os links devem abrir corretamente em uma nova aba.

Utilize uma configuração centralizada para os links oficiais:

INSTAGRAM_URL = "https://www.instagram.com/overbee.ow/"

DISCORD_INVITE_URL = "https://discord.gg/zYV9KNcr4"

Não utilize links fictícios ou placeholders. Esses são os links oficiais da OVERBEE.

Mantenha a identidade visual preta e amarela em todos os botões e seções de redes sociais.
